# Projet S7: IA pédagogique

Modèle d'IA de détection d'objets à but de démonstration lors d'activités pédagogiques sur l'IA.
Ce modèle permet de reconnaitre différents panneaux routiers ainsi que des obstacles tel que des voitures, des vélos ou des piétons.

Cette IA finale sera implémentée dans une voiture basée sur un microcontrolleur :

Vous Pouvez trouver ici le GitHub détaillant cette voiture : https://github.com/DytriiiX4/Voiture3roues.git
Certains des modèles d'IA seront implémentés sur le site pédagogique : https://github.com/BenMelu/GL_IA_ESEO_BBB_SITE
Vous trouverez ici la caméra dont le flux vidéo sera analysé par l'IA finale : https://github.com/DytriiiX4/CameraWebServer.git

Fait par Ghyslain COUPLAN et Lilian LEMERCIER

Branches:

main : Modèle final qui va être utilisé, ainsi que son dataset, composé de photos de panneaux et obstacles routiers prisent sur Angers

essai : essai pour se familiariser avec tensorflow, machines simples et modèles de CNN

ShapeModel : création d'un modèle CNN de détéction de formes: carré, cercle, triangle 

YoloEssai : Essai de modèle YOLO avec des dataset préfaits pour commprendre comment le modèle fonctionne.
